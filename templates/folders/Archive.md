# Archive

Closed chapters. **Read-only.**

1. **Don't update pages here.** If something turns out to be live again, move it back out.
2. **Don't link forward into the archive** from active pages unless the history is the point.
3. **Don't delete.** The archive exists so nothing had to be thrown away.

Only `weekly-review` moves files here, mirroring the original folder
(`Archive/Projects/`, `Archive/Organizations/`, `Archive/Superseded/`), and it logs each move
under `## Moved` in `Tracking/Signals/YYYY-MM-DD_weekly.md`: what, from where, to where, which
rule fired. That log is what makes a move reversible without git.

Search here only when the active vault comes up empty or the question is historical. Archived
content is stale by construction and will contradict current pages.
